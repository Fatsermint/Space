# Space game
### Space shooter game made in godot

## Controls
A/D 	move
F 		fire
esc		open settings/pause game
## Goal
Destroy all enemies before they go out of screen 
## Ai 
I didn't use any ai to make this project
## Levels
There are only 20 levels in this game. If you complete all the game the game chrashes
## Bugs
1. If you open settings while you aren't in a level the game may not stop when you open next time
2. Bullet may collide with enemies which are not on the screen yet
