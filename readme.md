# Space game
### Space shooter game made in godot

## Controls
A/D 	move
F 		fire
esc		open settings/pause game
## Goal
Destroy all enemies before they destroy you :o
## Ai 
Sometimes when I got stuck on a bug I used ai to tell me the problem with that bug but AI isn't made any code to this project.
## Levels
There are only 21 levels in this game. If you complete all the game the game chrashes
